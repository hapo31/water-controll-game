# 治水の神 — 水理PoC

地形を変えて水の流れを導き、移住してくる人々を洪水から守る、Godot 4 / GDScriptのゲームPoCです。タイトルから新規開始・保存データの再開を選び、ゲームオーバーまで遊べます。

## 起動

1. Godot 4標準版で `project.godot` を開きます。検証環境は **Godot 4.7.2 / Windows / Compatibility描画**です。
2. **F5**で実行します。開始シーンは `scenes/game.tscn` です。
3. 「新しく始める」を選びます。地形シードを指定でき、空欄なら毎回新しい値を生成します。
4. 地形生成のプログレスバーが終わったら「進める」で治水を始めます。

GodotがPATHにある場合は `godot --path .` でも起動できます。外部プラグイン・音素材・.NETは不要です。

## 遊び方

最初の2ターンは人が住む土地を整えます。神力は1000から始まり、盛土・掘削は1クリックで中心を100cm、周囲をなだらかに変えて、神力を10使います。画面右上が北です。

治水3分→雨15秒（4倍速）→結果の確認を繰り返します。1季節は2ターン、1年は8ターンです。治水は停止・倍速・確認付きのスキップができます。スキップでも残りの水理計算は行います。

2ターン経過後、夏の1ターン目に、浸水時間の割合が15%未満で、10×10マス内の高低差が100cm以内の土地へ最初の人が移住します。その後は半年（4ターン）ごとに移住し、3×4マスの家を作ります。家の人口は建築から1年ごとに増え、最大4人です。適地は薄いオレンジ色で表示されます。

雨では上流流入が2〜3倍または4〜6倍になり、山だけの雨と全域の雨があります。家が50cm未満の浸水で済めば住民1人につき神力を100得ます。1マスでも50cm以上ならその家から報酬を得られず、100cm以上なら住民を失って1軒につき神力が400減ります。

集計後に神力が0になった時、または水害で住民が全滅した時にゲームオーバーです。開始時の1年間はゲームオーバーになりません。結果とフェイズ演出の間は時間が止まり、左クリックで次へ進めます。

| 操作 | 動作 |
|---|---|
| 左クリック | 決定・マス選択・地形変更 |
| 右クリック | 水深・流量・最高水位をその場で表示 |
| Space | 治水中の停止 / 再生 |
| Tab | 2倍速 → 4倍速 → 等速 |
| 1 / 2 / 3 | 観察 / 盛土 / 掘削 |
| 中ドラッグ / WASD | 地図の移動 |
| ホイール | 拡大 / 縮小 |
| Home | 全体が見える視点へ戻す |
| F5 | 保存 |
| Esc | マス情報を閉じる |

左の操作欄はスクロールできます。「音を消す」で効果音・雨音を消せます。水深はcm、流量はcm³/sで表示し、平常流入は3か所合計1,800,000cm³/sです。

## 保存

1枠に自動・手動保存します。タイトルの「続きから始める」で再開できます。保存先はGodotの `user://suijin-save.dat`（通常のWindows環境では `%APPDATA%/Godot/app_userdata/治水の神 — 水理PoC/`）です。

地形シードは画面に表示します。シナリオシードは表示せず、両シード・乱数状態・水・地形・人口・浸水履歴・進行状況を保存します。新規ゲームの生成が完了すると保存枠を置き換えます。

ゲーム用地図は64×64のPerlin地形です。実際の水理計算で流入元と合流を追跡して川筋を3回掘ります。水理は標高＋水深の差による4近傍の保存的な計算です。被害のしきい値をcmで読めるゲーム用の尺度であり、実河川の予測モデルではありません。

```powershell
godot --headless --path . --editor --import
godot --headless --path . --script res://tests/test_water.gd
godot --headless --path . --script res://tests/test_game.gd
godot --path . --script res://tests/test_game_ui.gd
godot --path . --script res://tests/test_game_generation_ui.gd
godot --headless --path . --script res://tests/test_game_longrun.gd
godot --headless --path . --script res://tests/test_settlement_flatness.gd
```

`test_game.gd`は複数シードの生成も行うため、数分かかる場合があります。UI・長時間テストは前のテストで作った地図を使用します。UIテストは通常の描画ウィンドウで入力と表示を確認します。一時データと画像はGit対象外の `work/game/` に出します。ルールだけの確認は `tests/test_game_rules.gd` で実行できます。

## 残している実験室と拡張

`scenes/main.tscn` をF6実行すると、以前の256×256固定流域の水理実験室を起動できます。こちらの無次元単位・操作方法・自由な天候変更はゲームとは別です。既存のUI・天候・地形入力テストもこの実験室を対象にします。

研究・施設建設、チュートリアル、過去記録の閲覧画面は今回の範囲に含めません。チュートリアル状態とイベント記録を保存する接点を設け、後から画面を追加できるようにしています。水害の頻度や神力の経済を含め、面白さの調整は今後のプレイ評価で行います。
