# ゲーム内の言葉遣い

ゲーム中に表示する文言の表記と文体を定めるための文書です。全体方針を以下にまとめます。個別の文体や表記については、引き続き検討します。

## 決定事項

### 全体方針

ゲーム内テキストは、プレイヤーに必要なことを、ありのままに伝えます。LLMが書いたような不自然な言い回しや、読み応えを狙った装飾を避け、何が起きるか、何ができるかが分かる言葉を使います。

### ゲーム内テキストに書かないこと

- 日本の舞台や、その場面の時代にそぐわない表現は使いません。
- 視覚的な情報だけで十分に伝わることは、文章で重ねて説明しません。
- 内部処理に関わることは書きません。
- 説明を書くための場所ではないところに、説明を加えません。

気象や水害の言葉は、場面に合う日本語を選びます。言葉だけを機械的に置き換えず、伝えたい現象に合わせます。

| 避ける表現 | 言い換えに使う表現 |
|---|---|
| サイクロン、ハリケーン、スコール、雨季、ゲリラ豪雨 | 台風、大水、豪雨、梅雨、夕立 |

### 禁止する表現と言い換え方

- 体言止めは使いません。文章は、動作や状態を述べる形で書きます。たとえば「川の増水。」は「川の水が増えます。」とします。
- 「Aか、それともBか」のように、選択肢をもったいぶって示す表現は使いません。「AまたはB」と簡潔に示します。
- Appleのキャッチコピーのように、意味が曖昧なまま凄さを感じさせる表現は使いません。響きや読み応えより、事実やできることが伝わるかを重視します。たとえば「水の未来を、その手に。」は、実際の操作に合わせて「地形を変えて、水の流れを導きます。」とします。

## 今後決めること

今回のゲームPoCではユーザー指定の「神力」を使います。雨フェイズ・浸水フェイズを同じ区間として扱い、画面では「雨が降っています。」と伝えます。4〜6倍の全域の雨は「豪雨」と表示します。これは今回の仕様に対する表記であり、全体の用語や語り手を確定するものではありません。ボタンは「保存する」「盛土する」のように動作を示し、短い項目名の扱いは引き続き以下の論点に残します。

- プレイヤーへの呼びかけ方と語り手の立場
- UI、説明文、通知で使う文体
- 神力、叡智、信仰心などの用語と表記
- 漢字、かな、数字、記号の表記ルール
- ボタン名や見出しなど、短い名称に対する体言止め禁止の適用範囲
- 説明を書く場所の範囲と、各画面で伝える情報
- 禁止する表現の例外の扱い
