# 遊べるPoCのゲーム仕様

2026-10-04に提示された仕様と、同日の川筋生成に関する回答をまとめた文書。ゲーム仕様の基準は本書とする。過去の固定流域の設計・計測は実験室の記録として残す。

## コンセプトと範囲

治水の神として地形を変え、水の流れを導いて、人が住む土地を水害から守る。神力を使って盛土・掘削し、雨の被害と住民の生存から神力を得る。ゲームクリアはなく、ゲームオーバーまで季節と年が進む。

今回のPoCにはランダム地形、水理計算、タイトル、保存・再開、3フェイズ、神力、天候、移住、家、人口増加、被害集計、ゲームオーバー、効果音・雨の環境音を含める。人間による研究と施設建設は実装しない。

## 方位・単位

- 画面右上を北、右下を東、左下を南、左上を西とする。北端は配列の `y=0`、南端は `y=height-1`。東は `x` が増える方向。
- 水量は水深としてcmで表示する。流量はcm³/sで表示する。
- 水害の被害を直感的に把握できる規模にする。家の50cm・100cmの浸水が報酬と住民の生存に直結する。
- PoCの換算は水平1マス＝100cm、標高1内部単位＝100cm。セル面積は10,000cm²なので、内部水量1＝1,000,000cm³。水理の固定刻みは0.05秒。
- マスの流量は共有辺を通った水量の絶対値の合計を2で割った通過量を毎秒へ換算する。流向ベクトルの打ち消しによって合流地点の流量を過少表示しない。
- 最高水位はそのターンの最大水深をcmで表示する。地面からの深さと、標高基準の現在の水面高を分けて表示する。

## タイトルとシード

タイトルから「新しく始める」「続きから始める」を選べる。シードは2種類持つ。

| 種類 | 用途 | プレイヤーへの開示 |
|---|---|---|
| 地形シード | 起伏、山、流入地点、川岸の生成 | 開示する。新規開始時に手動指定できる |
| シナリオシード | 雨の種類・強さ、移住地点の抽選 | 開示しない |

新規開始時に地形シードを生成し、それから地形を作る。手動入力が空欄なら自動生成する。入力範囲は0〜2,147,483,647。シナリオシードは新規ゲームごとに別に生成する。同じ地形でも新しいゲームの天候・移住先は変わり得る。

保存には両シードと進行状況を含める。再開後のイベントが保存の前後で変わらないよう、シナリオ乱数の内部状態も保存する。

## 地形生成

毎ゲーム、Perlinノイズをベースに地形を生成する。PoCのゲーム用地図は64×64マス。以前の256×256固定流域は独立した実験室に残す。

1. 左下（南）へ向かって標高が下がる基本地形を作る。
2. 北端から5マス以内に基準点を3〜4個置き、各点を頂点とした山を作る。
3. 山の間に流入マスを3つ置く。
4. 実際の水理エンジンで水を流し、各マスで流入元を記録する。合流した水には元となった流入マスすべてを記録する。A・B由来の合流なら[A, B]を保持する。
5. 流量が最も多かったマスを0.5マス下げ、川の中心として印を付ける。同率はすべて対象にする。
6. 中心の東西1〜3マスを0.1〜0.4マス下げる。
7. 水を流して中心と川岸を掘る処理を合計3回行う。

**最大値の比較範囲は、ユーザーの回答により、各流入元・各南北区間の最大流量をつないで川筋を作る。** 実装では南北方向の各1行と流入元の組み合わせごとに比較し、合流元も組み合わせとして扱う。

生成途中の地形は表示せず、処理の進行に応じたプログレスバーを表示する。各回の流路計測は90水理秒、3回の掘削の後に40水理秒の流下を行って初期水量を整える。各回は新しい地形上で空の水域から計測を始める。

PoCでは南端を海への排水境界とする。海面高は0cmで固定し、実際に流れ込んだ水だけを排水する。海から逆流させない。

## 操作・表示・音

キーボードとマウスで操作し、決定は左クリックを基本とする。

| 操作 | 動作 |
|---|---|
| 左クリック | 決定、マスの選択、選択した地形変更の実行 |
| 右クリック | フォーカスしたマスの情報をその場のポップアップで表示 |
| Space | 治水中の時間停止・再生 |
| Tab | 治水中の2倍速→4倍速→等速の切り替え。開始時は等速 |
| 1 / 2 / 3 | 観察 / 盛土 / 掘削の切り替え |
| 中ドラッグ / WASD | 地図の移動 |
| ホイール | 拡大・縮小 |
| Home | 地図全体が見える視点へ戻す |
| F5 / 保存ボタン | 現在の状態を保存 |
| Esc | マス情報を閉じる |

ポップアップとステータス欄で、水量（水深）、流量、最高水位を確認できる。移住条件を満たすマスには、家の右上にチェックマークが付いたアイコンを表示する。標高・現在の水面高も表示する。流入量はゲーム画面で常に表示する。

決定、地形変化、イベント、フェイズ変化など、場面の切れ目に合った音を鳴らす。雨の間は雨の環境音を鳴らし、豪雨では強くする。PoCでは合成した効果音と雨音を使用し、外部素材を必要としない。画面から消音できる。

フェイズ演出・結果・スキップの確認中は水理計算と時計を止める。雨の環境音と雨粒も、雨フェイズの演出中には止める。

## 季節とフェイズ

リアルタイムに進行する。1季節は治水3分を2ターン行い、春→夏→秋→冬と進む。1年＝8ターン、半年＝4ターン。

```text
治水 180水理秒（通常は実時間3分）
  → 切り替え演出（停止）
  → 雨 60水理秒（実時間15秒、4倍速）
  → 集計・結果の確認（停止）
  → 次の治水の演出（停止）
```

「浸水フェイズ」と「雨フェイズ」は同じフェイズを指す。画面では「雨が降っています。」と伝える。

治水中も通常の上流流入と流下・蒸発が続く。雨の後の残留水を次の治水へ持ち越す。倍速は水理計算とフェイズ時計の両方に適用し、刻み幅は増やさない。

治水を飛ばすボタンは確認を出す。確認後、残りの時間分を処理可能な速さで水理計算してから雨へ移る。時計だけを進めない。処理中は進行状況を表示する。

フェイズごとに演出を出し、その間は時間を止める。PoCでは画面の出現を演出し、左クリックの「進める」で再開する。結果画面から次の治水へ進むのもプレイヤーが決定する。

## 神力と地形変更

- 開始時に神力を1000与える。最大値は設けない。
- 1回の地形変更で神力を10消費する。中心は1マス分（100cm）上下する。
- 周辺へなだらかに影響を広げる。PoCでは半径3マスの滑らかな重みで、距離に応じて変化量を減らす。
- 停止中・再生中のどちらも治水では変更できる。雨・集計・演出中は変更しない。
- 長押しによる自動連続消費は行わず、1クリックを1回の変更とする。
- 神力が10未満なら変更できない。海への排水境界は変更できない。
- 地形を変えても水量は消さず、新しい地面の高さをもとに水理計算で水を動かす。

## 雨イベントと流入量

雨フェイズに次のいずれかが起きる。種類と倍率はシナリオ乱数で抽選する。

| イベント | 流入マスの流量 | 地表への雨 |
|---|---|---|
| 山で雨が降る | 平常の2〜3倍 | 全体には降らない |
| 流域全体で雨が降る | 平常の2〜3倍 | 全体に降る |
| 山で豪雨が降る | 平常の4〜6倍 | 全体には降らない |
| 流域全体で豪雨が降る | 平常の4〜6倍 | 全体に降る |

原文の4番目も4〜6倍の強さなので、PoCでは「流域全体で豪雨が降っています。」と表示する。

平常流入は3マス合計1,800,000cm³/s、1マス600,000cm³/s。通常雨は合計3,600,000〜5,400,000cm³/s、豪雨は7,200,000〜10,800,000cm³/s。画面には合計値と各流入マスの値を出す。

山だけの天候は上流の増水に反映し、全域への直接降雨は加えない。全域の直接降雨はPoCでは通常雨0.15cm/s、豪雨0.45cm/sとする。15秒に圧縮されたゲーム用の雨量であり、現実の降雨強度を再現する値ではない。

## 集計と結果

家の12マスのうち1マスでも閾値に達したかを最大水深で判定する。治水開始からそのターンの雨終了までを記録し、水が引いても最大値を消さない。

| 家の最大水深 | 住民 | 神力 |
|---|---|---|
| 50cm未満 | 生存する | 1人につき+100 |
| 50cm以上100cm未満 | 生存する | その家から報酬を得られない |
| 100cm以上 | その家の住民を失う | 1軒につき−400 |

50cmと100cmは境界値を含む。罰則は人数に掛けず、複数軒なら各軒で−400。集計後の神力は0未満にならないよう0にする。

結果画面に生存者数・失った人数、神力の増加・減少、集計前後の神力、家ごとの人数・最高水位・被害を表示する。結果を確認し、次の計画を考えている間は時間を止める。結果画面で保存・再開しても報酬を二重に与えない。

## 発展・移住

人間が増える仕組みを発展システムと呼ぶ。研究や施設建設は今回実装しない。

ゲーム開始から1年後に最初の移住を試み、その後は半年ごとに試みる。PoCでは1回に1人・1軒。地点はマップ全体の適地の中からシナリオ乱数で選ぶ。

- ある雨の開始から、次々回の治水の開始までを1つの観測期間とする。
- 水に浸かっていた時間が15%未満のマスを適地とする。15%ちょうどは適地にしない。
- 少なくとも10×10マスのまとまった適地が必要。範囲内に条件を満たさないマスがあれば使えない。
- その10×10マスがある程度平坦であることも必要。範囲内の最高標高と最低標高の差を100cm以内とする。100cmちょうどは適地とし、内側の突起・窪みも含めて判定する。
- 条件を満たす土地を薄いオレンジ色にハイライトする。

PoCでは水深1cm以上を「水に浸かっていた」として各水理刻みで時間を積算する。完全な観測期間は、雨60秒＋治水180秒＋次の雨60秒＝300水理秒。停止・結果・演出中の実時間は分母に入れない。古い観測を捨て、ゲーム開始からの通算割合にはしない。

完了した観測割合は治水開始時に確定する。準備中の地形変更で適地を確認し直しても、その後の乾いた時間で完了した観測の浸水割合を薄めない。

海、川筋、流入マス、既存の家は配置候補にしない。適地がない時期には移住せず、通知を出して次の半年の機会を待つ。初回に適地がなく人がまだ来ていないだけでは「水害で全滅した」と判定しない。

地形変更と保存データの再開時にも、現在の標高で適地を判定し直す。移住の直前にも再確認する。以前の条件で建った家の住民を、条件変更だけで退去させない。

平坦さは高低差で判定するため、標高が高くても平坦な台地なら移住できる。高所が安全すぎる問題をさらに扱う場合は、生活に必要な水・耕地・交通などへの近さを別の移住条件として検討する。今回はその条件や標高の上限は追加しない。

## 家と人口

- 移住者は3×4マスの家を作る。
- 建築時、12マスすべてをその中で最も高かったマスの高さにそろえる。
- 新しい家の人口は1人。
- 建ってから1年（8ターン）ごとに1人増やす。最大4人。
- 水害で住民を失った家は無人の家として表示し、人口を再生させない。
- 家を作っても河道・残留水をリセットしない。

## ゲームオーバー

ゲームクリアや最終年は設けない。集計の結果、神力が0になるか、水害によって住民が全滅するとゲームオーバーになる。

開始時1年間の住民がいない期間はゲームオーバーにしない。全滅は一度人が移住してから判定する。ゲームオーバーでも結果を確認し、タイトルから新しく始められる。

## 保存

1つの保存枠を使う。新規開始・フェイズ変更時、ゲーム画面の約20秒ごと、手動保存、タイトルへ戻る時、通常のウィンドウ終了時に保存する。新規ゲームの地形生成が完了してから、それまでの枠を置き換える。

保存先は `user://suijin-save.dat`。両シード、乱数状態、年・ターン、フェイズ・経過時間、速度・停止状態、神力、地形・水・最高水位・流量、家・人口・成長時期、移住用の浸水履歴、結果、水量収支を保存する。

バージョン・ハッシュ・構造を検査し、不正な保存は再開候補にしない。一時ファイルを書き終えてから保存枠を置き換え、前回分を `.bak` に残す。書き込み失敗は画面で伝える。

## 将来の拡張

今回のPoCには次の画面を実装しないが、追加できる接点を残す。

- チュートリアル：`tutorial_state` に進行状態を追加できる。
- 過去の記録：何年生き残ったか、イベントと結果を閲覧する機能。`event_log` に雨、移住、集計とターン・時刻を保存し、将来のレポート画面が参照できる。

## PoCで補った点

値が指定されていない箇所は初期設定として扱い、ゲーム全体の最終仕様を確定しない。

| 項目 | 今回の設定・解釈 |
|---|---|
| 地図の大きさ | 64×64。10×10判定と倍速の水理計算を両立 |
| 物理換算 | 水平・垂直1マス＝100cm |
| 1回の移住人数 | 1人・1軒 |
| 浸水の最小水深 | 1cm。微小な水膜を移住不可にしない |
| 移住地の平坦さ | 10×10マス内の高低差が100cm以内 |
| 演出の終了 | 「進める」を左クリック |
| 最高水位の範囲 | 治水開始から同ターンの雨終了まで |
| 4〜6倍の全域の雨 | 豪雨として表示 |
| 基本流入・全域降雨 | 上記のゲーム用係数。被害頻度の調整余地を残す |

文体と用語の全体方針は [ゲーム内の言葉遣い](game-language.md) を参照する。
