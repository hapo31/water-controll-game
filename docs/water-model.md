# 水シミュレーションの最小仕様

> 本書の無次元単位と固定256×256マップは実験室の仕様です。ゲームPoCは同じ計算を64×64の生成地形に適用し、1内部単位＝100cmとして表示します。現在の天候・流入・被害は [ゲーム仕様](game-specification.md) を参照してください。任意の由来追跡・通過流量計測は水量移動の計算を変更しません。

## 単位と固定刻み

セル面積1、標高z、水量（水深）h、水面高H=z+h。ゲーム内単位を使い、現実の距離・雨量・時間には換算しない。固定刻みは0.05実験秒。描画と水計算を別スレッドに分ける。処理が間に合わない場合は実験時間が実時間より遅く進み、刻み幅を増やして補わない。

## 水位差による移動

4近傍の共有辺を、横の偶数・奇数、縦の偶数・奇数の4群に分ける。同じ群の辺は端点を共有しない。1組のマスについて、次の量を高い水面から低い水面へ移す。

```text
weight(t) = (1 - exp(-2 * conductivity * t)) / 2
transfer = clamp(weight(t) * (H[a] - H[b]), -water[b], water[a])
water[a] -= transfer
water[b] += transfer
conductivity = 30
```

水位差が2倍なら、利用可能な水量の範囲で移動量も2倍。水位差がゼロなら移動しない。重みは0.5未満なので、1組の水面を追い越す移動は起こらない。乾いた高地から水を発生させず、相手の地面より水面が低いときは乗り越えない。

共有辺の両側の水量が0なら移動量は必ず0になるため、その辺の水位差計算を省く。各走査のその時点の水量で判定し、直前にほかの辺から流れ込んだ水は通常どおり移す。水理刻みや走査順は変えない。

1tickは `横偶→横奇→縦偶→縦奇→縦偶→横奇→横偶` の対称な順序で完結させる。中央の縦奇だけdt、ほかはdt/2の重みを使う。各辺の更新時間の合計はdt。往路と復路の途中は画面へ公開しない。tickごとに順序を反転する方式は、薄い水が交互に移動して点滅するため使用しない。

これは辺ごとの緩和を組み合わせた簡略モデル。旧版の全辺同時更新・7分割方式と数値軌道は同じではない。流速の慣性、波、浸透、侵食は扱わず、有限刻みの方向依存性も残る。係数を大きくしても、1組のマスが同水位になる以上の移動はしない。

## 1tickの処理

1. 上流15マスに各1.2×dtの流入を追加する。
2. 海以外にrain_rate×dtを加える。
3. 対称な7回の走査で隣接水量を移す。同じ辺の移動量を加算して流向表示に使う。
4. 海に渡した量を直ちに排水台帳へ加え、海の実水量を0に保つ。
5. 陸域の残水量を上限に蒸発させ、最大水深と流向を更新する。
6. 完成した状態だけを表示側へ公開する。

単体検証用の固定量排水セルも引き続きサポートする。新しい固定マップの排水域は海であり、旧マップの毎秒4.8という下流排水上限は適用しない。

## 山地から海までの固定マップ

256×256。山地の3本の支流が、中央の湖へ合流する。湖の出口から本流が蛇行して沿岸の海へ注ぐ。固定シードの起伏、山の尾根、河谷、低地の窪地を含む。各上流端は川幅5マス、3支流合計15マスで、毎秒18の固定流入になる。

湖の初期水面高は5.5。湖底は縁ほど浅く、川の初期水深は0.7。支流から湖、湖から海まで、水面高が下がる4近傍の経路を自動検証する。マップの外周は流入端を除いて閉鎖境界。

## 海

- seaフラグのセルは地形編集不可。フルリセットまで範囲は変わらない。
- 表示上の水面高は常に0。見かけの水深は `0 - 海底標高`。
- 実際の保有水量は0。陸から海へ渡った水はその場で全量を排水として記録する。
- 海への流れも隣接する水面高の差で決まる。海面より低い水面から海へ吸い上げない。
- 海は一方向の排水境界であり、海から陸へ水は供給しない。海面以下を掘っても逆流は起こらない。
- 海の表示用の水に降雨・蒸発を適用しない。見かけの海水を総水量・浸水セル数・水量収支に含めない。

## 天候と初期化

| パラメータ | 晴れ | 通常 | 豪雨 |
|---|---:|---:|---:|
| 降雨率（海以外の1セルあたり） | 0 | 0.003 | 0.012 |
| 上流流入率（15セル合計） | 18 | 18 | 18 |
| 蒸発率（残水量で制限） | 0.006 | 0.0005 | 0.0005 |

天候変更は雨量と蒸発率だけを変え、水・地形・時計・計測値・再生状態を保持する。水の初期化は起動時に保存した川と湖の水量を復元し、水の計測台帳を初期化する。編集済み地形・天候・時計・再生状態は維持する。地形の初期化は水を含むフルリセットで、豪雨選択・一時停止へ戻る。

## 収支と浸水

```text
現在の陸域の水量 = 初期水量 + 累積降雨 + 累積流入 - 海への累積排水 - 累積蒸発
```

倍精度の水量配列を使う。閉鎖系の誤差1e-8以下、256×256流域で1e-6以下を検証する。河道・湖・海以外で水深0.25以上を浸水とし、現在と浸水経験を分けて数える。旧64×64の特定堤防座標を監視する越水量は、新マップの統計から外した。堤防を越える原理自体は、小さい独立モデルの回帰検証を維持する。

## 表示の安定性

表示用テクスチャは完成済みの計算結果から作り、水計算の途中は読まない。薄い水の不透明度は深さ0〜0.04の間で連続的に変え、特定の深さで突然オン・オフにしない。流向矢印も水深と移動量に応じて連続的に薄くする。表示上の調整は実水量へ書き戻さない。
